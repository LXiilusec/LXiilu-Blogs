# Webshell
先来理解webshell是什么，把服务器比喻成一个小房子，这时候我要进去搞点破坏，我可呢规定不能光明正大的拿着工具进去，所以我把我的工具打包一下，伪装成其他东西带进去，进入房子后，在房子里装一个后门，这个门的钥匙只有我有，而我通过这个后门把我要执行的破坏命令丢进去，这个Webshell就相当于是我的后门，伪装这一步就是我把一个用来搞破坏的文件伪装成正常文件，而我写在这个文件里的程序会被服务器当成正常文件去执行，从而达成破坏的目的。

这里补充纠正一下部分理解：
* Webshell的首要目的不是破坏，而是控制：
  

| 用途                 | 说明                                                         |
| ------------------ | ---------------------------------------------------------- |
| 远程执行命令             | 相遇拿到了一个命令行                                                 |
| 文件管理               | 上传/下载/删除文件（蚁剑的文件管理就是做这个的                                   |
| 数据窃取               | 查看数据库，饭配置文件找密码啥的                                           |
| 持久化                | 下一次还能进入这个服务器（具体怎么做还不知道....）                                |
| 横向移动（虽然不知道为什么叫这名字） | 通过这个服务器在进入其他服务器？                                           |
| 提权                 | 把一个“低权限账号”变成“高权限账号”[^1]，从 Web 权限提到 root。<br><br>[^1]: <br> |

[^1]: 为什么要提权：所以拿到 webshell ≠ 拿到服务器。你只能看网站目录，看不到系统密码文件，删不了系统服务。 想真正控制这台机器，就得提权。
